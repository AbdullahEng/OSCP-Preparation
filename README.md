> My self-study journey to the **Offensive Security Certified Professional (OSCP+)** certification — the notes, methodology, tools, and lab writeups I build along the way. Everything here is done in isolated lab environments and on platforms with explicit authorisation.

I'm a cybersecurity diploma student training myself toward the OSCP over a structured 9-month plan (~12 hrs/week), using AI as a study guide and my own laptop as an isolated lab. This repo is my public proof of work — and my accountability.

---

## 🗺️ The Roadmap

A 39-week plan across five phases, ending with the exam in **mid-2027**.

| Phase | Focus | Weeks | Status |
|-------|-------|:-----:|:------:|
| **0 · Foundations** | Lab, notes, methodology, this repo | 1–2 | 🟨 In progress |
| **1 · Recon, Web & First Blood** | Enumeration + web attacks (fits around industrial training) | 3–14 | ⬜ Upcoming |
| **2 · Exploitation & Privilege Escalation** | Shells, exploits, Linux/Windows privesc | 15–22 | ⬜ Upcoming |
| **3 · Active Directory & Pivoting** | The 40-point exam half | 23–30 | ⬜ Upcoming |
| **4 · Exam Simulation & Report** | Mock exams, reporting, the real thing | 31–39 | ⬜ Upcoming |

> Legend: ✅ done · 🟨 in progress · ⬜ upcoming

## 🎯 The exam I'm training for

| | |
|---|---|
| **Pass mark** | 70 / 100 |
| **Standalone machines** | 3 × 20 pts = 60 (shell + privesc) |
| **Active Directory set** | 3 chained machines = 40 pts |
| **Format** | 24 h hands-on + 24 h report |
| **Metasploit** | One machine only, never for pivoting |
