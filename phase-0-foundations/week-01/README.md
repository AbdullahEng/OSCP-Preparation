# 🚀 Week 1 — Lab & Battle Station

> **Phase 0 · Foundations** · The setup week. Nothing gets hacked yet — and that's exactly the point.
> By Sunday night you have a working Kali lab, a snapshot to fall back on, a note-taking system, your GitHub repo live with this week committed, and you *know* what the OSCP+ exam asks of you. Everything else in this journey stands on this week.

**Pace this week:** Gear 1 (around the internship) — ~**6–7 hours total**
**Shape:** 5 short weekday sessions (20–40 min: reading + flashcards + small installs) **+ one weekend block (4–5 h: the hands-on build + a warm-up room).**

---

## 🎯 Objectives — what "done" looks like

- [ ] Kali Linux running in VirtualBox, fully updated, with a clean **snapshot** named `clean-updated-base`
- [ ] Lab networking understood: **NAT vs Host-Only** — and your adapters set safely
- [ ] Disk plan sorted (FYP VMs export plan, so there's room for targets later)
- [ ] Note-taking system live (Obsidian vault + per-box template) + screenshot workflow (Flameshot)
- [ ] GitHub repo **live** with this `week-01/` folder committed and pushed
- [ ] OSCP+ exam rules read on OffSec's site and rewritten **in your own words**
- [ ] Core Kali toolkit verified present (`which …`)
- [ ] **One** easy TryHackMe room done end-to-end using the full pipeline (notes → screenshot → commit)

## 🗓️ Suggested Gear-1 schedule

| When | ~Time | Focus |
|------|:----:|-------|
| **Mon** | 30 min | Kick off the Kali image download (it runs in the background). Read the OSCP+ exam guide; jot the facts in your own words. |
| **Tue** | 30 min | Lab networking concept (NAT vs Host-Only). Sketch your disk plan. |
| **Wed** | 30 min | Note-taking: install Obsidian, create the vault + box template. |
| **Thu** | 30 min | Skim the toolkit list; learn `tmux` basics. Review flashcards. |
| **Fri** | 20 min | Light flashcard review. Read the weekend mission so you start Saturday already moving. |
| **Sat/Sun** | 4–5 h | **The block:** boot → update → snapshot Kali → networking → notes → commit `week-01/` → verify toolkit → one warm-up TryHackMe room, fully documented. |

> The split is deliberate: weekdays stay light around the 9-to-6, and all the hands-on lands in the weekend block. If a weekday slips, the weekend block still carries the week.

- [ ] Could I re-image Kali from a snapshot if it broke? *(Yes = you understand snapshots.)*

- [ ] Is my repo live with the README, tools reference, and this week's folder pushed?
- [ ] Can I recite the OSCP+ scoring from memory? *(70 to pass · 60 standalone + 40 AD.)*

All four yes → **Week 1 complete.** You're no longer setting up; you have a lab. 🔥
